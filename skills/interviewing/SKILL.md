# interviewing — 訪談紀律

把待釐清的事項當成一棵決策樹來工作：每個決定底下掛著依賴它的後續決定。

## 規則

1. **以輪為單位**。每一輪，把「前提都已確定、現在就能問」的問題**一次全部問完**，不要擠牙膏式一題一題丟。答案還依賴其他未決問題的，留到下一輪。
2. **每題附推薦答案**。使用者可以只回「都用你的建議」就前進一輪。
3. **只問決定，不問事實**。查得到的（檔案內容、現有行為、外部規格）自己查；問使用者的必須是取捨。
4. **查證不阻塞訪談**。要查的事實派 sub-agent 在背景查，訪談不停——查證中的事實是未確定的前提，**只有依賴它的問題等結果**，其餘 frontier 照問；結果回來後，被擋住的問題排進下一輪。
5. **問題格式**：

```
❓ **Q1 - <標題>**：<問題內容，選擇題附 (A)(B)(C) 選項與各自的後果>

➡️ <推薦答案＋一句理由>
```

6. **收到答案後**：重算決策樹，被解鎖的問題進下一輪；全部收斂就結束訪談，向使用者摘要所有已定案的決定。
7. **使用者的答案推翻先前決定時**：明確指出受影響的舊決定，確認後一起更新，不默默吞掉矛盾。
